# 🎤 VoicePlatform

A production-ready, two-stage VAD+ASR pipeline that detects speech segments with Pyannote Audio and transcribes them with NVIDIA NeMo Parakeet, exposed through an OpenAI-compatible HTTP API built on FastAPI and Ray Serve.
